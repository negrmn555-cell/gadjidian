## Профили и сервер

- [x] Пять профилей чата плюс один независимый профиль сортировщика. Выключенные профили
  занимают слот; сортировщик в лимит пяти не входит.
- [x] Добавление, изменение, удаление, включение, выбор основного ИИ и проверка подключения.
- [x] Поддержка OpenAI-совместимого Chat Completions API. Нативные API Anthropic/Gemini
  потребуют отдельных адаптеров; совместимые шлюзы используют текущий адаптер.
- [x] SQLite migration v3: профили и неизменяемые версии. Обновление и удаление требуют
  expectedVersion. Конкурентный шестой профиль возвращает 409.
- [x] API-ключ шифруется AES-256-GCM с привязкой к ID и версии; API возвращает только
  hasSecret. Редактор предлагает сохранить, заменить или удалить ключ.
- [x] Смена сервера API требует явной замены/удаления ключа. Сохранённый ключ в форму
  не загружается и в ответах/ошибках не выводится.
- [x] Каждый запрос фиксирует выбранный профиль, модель и ключ до начала выполнения.
  Изменение профиля не перенаправляет уже начатый запрос; используемую версию нельзя удалить.
- [x] Лимиты: два параллельных запроса на профиль независимо от числа версий, восемь суммарно.
  Освобождение допуска идемпотентно. Есть общий таймаут, ограничение запроса и ответа.
- [x] HTTPS по умолчанию, запрет URL с credentials/query/fragment, закрытых адресов и
  перенаправлений. DNS проверяется при каждом запросе; соединение закреплено за проверенным
  адресом, имя сервера и проверка TLS сохраняются. Ограничен и распакованный ответ.
- [x] Проверка подключения использует синтетический запрос, не читает vault/историю и
  не выполняет инструменты. Для чата проверяется инертный relay_ping, для сортировщика — JSON.
  Результат относится к конкретной версии профиля; изменение сбрасывает его.
- [x] Заявленные возможности отделены от проверенных. Vision сейчас не проверяется.
  Если проверка опровергла tool calls, обычный запрос с ними отклоняется с понятной ошибкой.
- [x] LLM_* импортируется один раз при первом запуске новой схемы. Удаление профиля
  не приводит к его повторному появлению из ENV. Скрытого переключения на ENV нет.

Идентификаторы моделей OpenAI/OpenRouter нормализуются автоматически. Для произвольного
совместимого API идентичность модели задаёт пользователь: сервер не может доказать,
какая модель скрыта за чужим alias. Одинаковая модель отмечается в настройках как
неподходящая для сортировки. Планировщик сортировки и SMS пока не запускаются.

## Контракты

Браузерные типы и валидатор находятся в packages/core/src/contracts.ts:
ProviderPublic, ProviderWrite, ProviderPage, ProviderTestResult, validateProviderWrite.
Секретное поле доступно только во входном ProviderWrite.secretUpdate.

Авторизация всех маршрутов — ключ устройства приложения; quick-key не подходит.

| Маршрут | Тело / результат |
| --- | --- |
| GET /api/providers | ProviderPage |
| POST /api/providers | { slot, provider: ProviderWrite } → ProviderPublic |
| PATCH /api/providers/:id | ProviderWrite с expectedVersion → ProviderPublic |
| DELETE /api/providers/:id | { expectedVersion } |
| PUT /api/providers/default | { providerId: string \| null, expectedVersion? } → ProviderPage |
| POST /api/providers/:id/test | ProviderTestResult |

Ошибки: 401 — авторизация, 404 — профиль не найден, 409 — лимит, конфликт версии
или использование профиля, 422 — формат/политика адреса/несовместимая возможность,
429 — параллельные запросы. Ошибка подключения не раскрывает тело upstream-ответа.

## Эксплуатация

Master key — 32 байта из PROVIDER_MASTER_KEY (base64) либо постоянный файл
PROVIDER_KEY_FILE, по умолчанию DATA_DIR/secrets/provider-master.key вне vault.
Файл не должен попадать в Git. Сохраняйте его отдельно от базы в защищённой резервной копии:
без прежнего ключа зашифрованные API-ключи не восстановить. При отсутствующем или неверном
ключе существующих профилей сервер отказывает в запуске и не подменяет ключ новым.
Автоматическая смена master key с повторным шифрованием пока не реализована.
Замена API-ключа отдельного профиля реализована.

Локальные HTTP API доступны только после настройки сервером PROVIDER_ALLOWED_ORIGINS
с точными origin, например http://127.0.0.1:11434. Этот список исключений не редактируется
в мобильном приложении. Таймаут задаётся PROVIDER_TIMEOUT_MS; транспорт ограничивает его
диапазоном 1–120 секунд. Режим одного процесса-писателя из первого этапа сохраняется.
