# Выпуск 0.2.0

Агентская среда для заметок, задач, поиска и памяти:

- Orama с русским поиском, структурный Markdown и инкрементальный индекс.
- Потоковые ответы, восстановление прогресса и фоновая суммаризация.
- Mastra с ограниченными инструментами, бюджетами и безопасными мутациями.
- Явные постоянные предпочтения в Markdown и разрешение конфликтов с Obsidian.
- Карточки действий, источники, подтверждённые записи и частичные результаты.
- Локальное извлечение документов, OCR и отдельное объяснение страниц PDF моделью.
- Обезличенные метрики Langfuse и расширенные сценарии Promptfoo.
- Отзываемые MCP-ключи для внешнего поиска и чтения; инструменты записи не выставлены.

Проверки перед выпуском: 166 тестов, typecheck/build, 80 поисковых и 14 агентских
сценариев Promptfoo, интерфейс 320/390/1440 px и изолированная production-установка.
Эти результаты относятся к локальному стенду; проверка развёртывания выполняется
отдельно. Подробности — в отчётах `agent-platform-stage-*`.

Обновление требует сохранения `.env`, обеих SQLite вместе с WAL, ключей шифрования,
vault и существующих volumes. Миграции основной базы — до версии 8; краткосрочные
таблицы расширяются отдельно. Не удаляйте volumes при обычном обновлении.

По умолчанию внешний экспорт Langfuse выключен. Для него нужны ключи проекта и
настройка срока хранения на стороне Langfuse. MCP-ключи создаются в настройках
приложения. PDF по-прежнему ограничен 5 МиБ. Лимит CPU контейнера задаёт `RELAY_CPUS`
(по умолчанию 1). Docker-образ сохраняет revision коммита в OCI label.
Сборщик закрепляет npm 11.17.0 — ту же версию, которой подготовлен lockfile.
Рабочие зависимости устанавливаются чисто в отдельной стадии с повторным
использованием кеша сборки; копирования и удаления dev-пакетов из OverlayFS нет.
Для сборки требуется BuildKit. Код приложения в рабочем образе доступен только для чтения.
