# Gadjidian: округление, стекло и движение

Изменения внесены в рабочую копию приложения. На рабочий сервер не публиковались.

## Что изменено

- Единая система радиусов: круглые кнопки с иконками, капсулы вкладок и действий, панели 24–30 px, поля 16 px. Значки заметки и файла получили округлённый контур.
- Стеклянный материал для навигации, переключателей, панели ввода, меню, графовых инструментов, истории и диалогов: полупрозрачная подложка, размытие фона, светлый край и мягкая тень. Карточки с текстом остаются почти непрозрачными.
- Лиловые, голубые и розовые оттенки согласованы со стартовой анимацией. Жёлтая кнопка режима заменена лилово-голубой.
- Нижняя навигация стала плавающей капсулой со скользящим выделением; нажатия дают немедленное небольшое сжатие и плавный возврат. Обработчики действий не задерживаются ради анимаций.
- `ChatThinking` отображается внутри реального pending-ответа: сияющая сфера, живой текст статуса, компактное состояние при потоковом тексте. При завершении/ошибке/отмене элемент удаляется вместе с pending-состоянием.
- Добавлены непрозрачные варианты для reduced transparency / повышенной контрастности / отсутствия backdrop-filter, а также статичный вариант ожидания при reduced motion.
- Исправлен перенос длинного текста в карточках настроек, который вызывал внутреннюю горизонтальную прокрутку на 320 px.

## Проверки

- `npm.cmd run build --workspace @relay/app`: успешно, включая TypeScript и PWA-сборку.
- `git diff --check -- packages/app`: ошибок пробелов нет (Git сообщает только о будущей нормализации CRLF).
- Изолированный локальный сервер 127.0.0.1:8092, отдельная тестовая база и Git-sync отключён. Пользовательский профиль ИИ в этой базе не изменялся; запросы внешнему провайдеру не отправлялись.
- Браузер: чат и задачи на 390 px; календарь, граф, новая задача, настройки и диалог чата на 320 px; настольные задачи на 1440 px. Проверенные страницы не имеют горизонтального переполнения документа.
- После исправления настройки на 320 px: `clientWidth=286`, `scrollWidth=286` у прокручиваемой области.
- Диалог чата: Shift+Tab с кнопки закрытия переходит на последний элемент; Escape закрывает окно, снимает inert и возвращает фокус на «Чат: модель и память».
- Изолированный браузерный стенд использовал настоящий `Chat.tsx` с подменённым локальным транспортом: отправка → pending, snapshot → потоковый текст, завершение → индикаторов 0, отмена → индикаторов 0 и восстановленный черновик, ошибка → индикаторов 0 и сообщение об ошибке. Стенд находится в игнорируемой папке `data/focus-glass-qa`; он не входит в исходники продукта или PWA-сборку.
- CSS-ветки reduced motion, reduced transparency и forced colors проверены по коду; отдельная эмуляция системных настроек браузером не проводилась. Safari/iOS на физическом устройстве не проверялись.

## Референсы и решения

- [apple-design](https://github.com/emilkowalski/skills/blob/main/skills/apple-design/SKILL.md): мгновенный отклик на нажатие, материалы по иерархии, читаемость и доступность.
- [union-tab-view](https://github.com/unionst/union-tab-view): плавающая капсула и скользящее выделение. Это SwiftUI-пакет; использован как визуальный ориентир.
- [LiquidGlassKit](https://github.com/muhittincamdali/LiquidGlassKit): светлый край, оттенок материала и непрозрачный fallback; также SwiftUI, без прямой установки в веб-проект.
- [liquid-glass-react](https://github.com/rdev/liquid-glass-react): изучен как ориентир преломления и бликов. README отмечает частичную поддержку displacement в Safari/Firefox. Здесь реализована собственная CSS-адаптация без тяжёлого фильтра преломления текста и без новой зависимости.
- [awesome-ios-animation](https://github.com/v5tech/awesome-ios-animation): коллекция ориентиров для физических откликов и индикаторов.
- Ссылка `YamilAyma/atexteffect` вернула 404; её код не использовался.
