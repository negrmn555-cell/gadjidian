# Gadjidian: интерактивный граф заметок

Изменения подготовлены к публикации на VPS. Итог развёртывания проверяется по ревизии контейнера, публичным ресурсам и API.

## Поведение

- При каждом входе в «Заметки» первым открывается граф. Отдельный вид «Список» сохранён; дублирующий список внутри графа удалён.
- Тёмное полотно, тонкие связи и узлы разного размера ориентированы на приложенный референс. Радиус зависит от числа реальных связей.
- Физическая модель включает пружины связей, отталкивание, затухание и мягкое притяжение сообществ по меткам. Перетаскиваемый узел закрепляется под указателем; движение передаётся по цепочке связей. Группы по меткам не создают вымышленных рёбер.
- У меток устойчивые цвета, нормализованные по регистру и ведущему #. Несколько меток дают градиент из их цветов; узлы без меток наследуют палитру ближайшего связанного сообщества. При входе случайные градиенты примерно за 1,8 секунды переходят к смысловой палитре.
- API графа возвращает YAML-метки и метки обычного Markdown-текста. Примеры внутри inline code и fenced code исключены. Результат разбора кешируется по хешу содержимого с ограничением размера.
- Мышь: перетаскивание фона и узлов, масштабирование колесом относительно курсора. Телефон: перемещение одним пальцем, масштабирование и перемещение двумя пальцами, корректное продолжение одним пальцем после pinch. Кнопки +/−/«Вписать» удалены.
- Двойное нажатие переключает полноэкранное полотно в пределах окна браузера; повторное нажатие сворачивает. Есть клавиша Escape и кнопка закрытия. Enter на полотне также переключает режим, Home возвращает композицию в кадр.
- Нажатие на узел открывает стеклянное окно с заголовком, Markdown, ссылками и связанными заметками. Доступны существующий редактор, исходник Markdown/YAML, предпросмотр и сохранение через действующую проверку хеша и Git. Wikilinks открываются внутри окна, без накопления модальных окон.
- Поддержаны reduced motion, повышенная контрастность и reduced transparency. В фоне вкладки физика останавливается; после стабилизации кадры не запрашиваются до нового взаимодействия.

## Проверки

- Полная сборка проекта прошла; финальная сборка интерфейса после последней настройки анимации также прошла.
- Core: 38 тестов; server: 147; app: 4. Все прошли. Новые проверки покрывают размер хабов, конечность координат, устойчивые цвета/градиенты, наследование палитры, притяжение соседей при перетаскивании и группировку по меткам без ложных рёбер. Серверный тест проверяет YAML + кириллические inline-метки и исключение кода.
- В браузере использован отдельный QA vault: 97 демонстрационных и ранее существовавших тестовых записей, 198 связей. Пользовательское рабочее Git-хранилище не изменялось.
- Мышью проверено движение узла и связанных соседей; колесо изменило масштаб с 0,5385 до 0,7269. Двойной клик открыл и закрыл полный экран, inert корректно устанавливался и снимался.
- На отдельном стенде настоящий компонент графа получил синтетические Touch Pointer Events: pinch изменил масштаб ровно вдвое, переход с двух пальцев на один не открыл заметку; двойной touch tap открыл и закрыл полный экран. Физический телефон в этой итерации не использовался.
- Проверены окно заметки, редактор, исходник, предпросмотр и переход по wikilink: после перехода оставалось одно окно. Сохраняется фокус и клавиатурное закрытие.
- Список отсутствует внутри графа, кнопки прежних элементов управления отсутствуют. При возврате из списка через чат снова выбран граф.
- Файлы стенда и демонстрационных данных находятся в игнорируемом `data/focus-glass-qa`, не входят в исходники приложения или PWA precache.
